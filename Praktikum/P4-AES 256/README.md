## 📌 Deskripsi
Project ini merupakan implementasi **enkripsi dan dekripsi file menggunakan algoritma AES-256** berbasis Python yang dijalankan di Google Colab.

File yang dienkripsi akan berubah menjadi **ciphertext** dengan ekstensi `.enc` dan hanya dapat dikembalikan menggunakan password yang benar.

---

## 🚀 Fitur Utama
- 🔐 Enkripsi file menggunakan AES-256  
- 🔓 Dekripsi file dengan password  
- 📂 Upload & download file (Google Colab)  
- 🛡️ Proteksi data dari akses tidak sah

## 🧠 Cara Kerja Singkat
1. User upload file  
2. Input password  
3. File dienkripsi → `.enc`  
4. Untuk membuka → harus dekripsi pakai password yang sama  

---

## 🔐 Contoh Hasil
| File | Status |
|------|-------|
| `pdki.txt` | ✅ Bisa dibaca |
| `pdki.txt.enc` | ❌ Tidak terbaca (ciphertext) |

---

## ⚠️ Catatan Penting
File hasil enkripsi **tidak dapat dibuka tanpa proses dekripsi**.  
Jika password salah, file tidak akan bisa dikembalikan ke bentuk semula.
